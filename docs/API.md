# REST API

База: `http://127.0.0.1:8000/api`. В браузере использовать относительный `/api` через Vite proxy. Контракты response_model проверяются Pydantic, OpenAPI доступна в `/docs`. Пользователь в этапе 1 фиксирован: demo user id=1. Клиент не может подменить user_id в PUT.

## Реализовано

| Метод | Маршрут | Результат |
|---|---|---|
| GET | /health | status и версия миграции. Возвращает 503, если БД недоступна, требует миграции или заполнения |
| GET | /dashboard | Уроки, прогресс, открытые вопросы, число локальных попыток, отдельная история чата |
| GET | /lessons | Четыре LessonSummary |
| GET | /lessons/{id} | Разделы, отметки, источник и статус каждого факта |
| PUT | /sections/{id}/progress | Идемпотентное сохранение отметки |
| GET | /terms?q= | Поиск по термину/определению без изменения исходного текста |
| GET | /facts | Реестр выбранных фактов и их статусов |
| GET | /conflicts | Вопросы к тренеру с одной или обеими версиями |

Пример тела PUT:

```json
{"completed": true}
```

Ответ:

```json
{"section_id": 1, "completed": true, "lesson_id": 1}
```

`completed` — строго boolean; строка `"true"`, лишние поля и отсутствующее поле дают 422. Несуществующий урок/раздел — 404. Чужой Origin при записи — 403. Неизвестный Host — 400. Неудачное сохранение не изменяет UI. Ответы помечены Cache-Control: no-store; TanStack Query управляет только оперативным кэшем.

FactOut: `id, topic, statement, source_file, source_page_or_slide, effective_date, review_status, needs_trainer_confirmation`. Поле `source_page_or_slide` может содержать точный лист и строку XLSX. Абсолютные пути, оригиналы, изображения, ключи ответов не выдаются.

LessonSummary: `id, day, title, total_sections, completed_sections, progress_percent`. Процент округляется от отношения прочитанных разделов ко всем разделам. Итоговый Dashboard считает долю всех 22 разделов, а не среднее процентов по дням. Прочитанный урок не означает сданный экзамен.

Поиск словаря использует Python casefold для корректной кириллицы. При 64 терминах достаточно выборки в памяти; для большого словаря добавить нормализованный индекс/FTS. Пагинация пока не нужна для фиксированного пакета.

## Учебная CRM

| Метод | Маршрут под /api | Результат |
|---|---|---|
| GET | /crm/customers?q= | Поиск по учебному ID или имени без учёта регистра |
| GET | /crm/customers/{id} | Клиент, счета, карты, движения, депозит, кредит, бонусы, тикеты с журналами и доступные темы |
| GET | /crm/tickets?status= | Очередь учебного оператора с необязательным фильтром статуса |
| POST | /crm/customers/{id}/tickets | Создать тикет по теме из справочника |
| PUT | /crm/tickets/{id}/status | Выполнить очередной переход статуса |

Для создания передайте JSON с `topic` из `ticket_topics` карточки и `request_id` в формате UUID. Для перехода передайте `status` из `next_status`, текущую `version` и новый UUID. Учебный цикл проходит через `open → in_progress → resolved → open`. Успешная запись и точный повтор команды возвращают HTTP 200 и текущее представление тикета. Повтор ключа с другой командой, устаревшая версия и недоступный переход возвращают 409. Неизвестный клиент или тикет возвращает 404. Текст темы берётся из справочника.

Журнал содержит исходный и новый статусы, оператора и время UTC. У стартовых записей время отсутствует. Карточка читает статус и журнал из одного снимка SQLite. Продукты, остатки и баллы доступны для чтения. Денежные значения API передаёт в минимальных единицах валюты счёта.

Идентификаторы в путях должны быть положительными целыми числами в диапазоне SQLite. Значения вне диапазона возвращают 422. При потере ответа на создание тикета браузер сохраняет исходную команду до подтверждения и использует тот же UUID при повторе после перезагрузки вкладки.

## Спроектировано, не реализовано

| Метод/маршрут | Назначение и инвариант |
|---|---|
| POST /exam-attempts | day или final; строго 15 опубликованных вопросов дня либо 40 итоговых, по 10 на день; 409, если недостаточно проверенных |
| GET /exam-attempts/{id} | Восстановить порядок и позицию из AttemptQuestion; не раскрывать ключ до обратной связи |
| PUT /exam-attempts/{id}/answers/{question_id} | Идемпотентный ответ, проверка принадлежности вопроса попытке |
| POST /exam-attempts/{id}/submit | Зафиксировать попытку; открытые ответы pending до рубрики/ревью |
| GET /exam-attempts | История, баллы, ошибки и слабые темы |
| GET /roleplay-scenarios; POST /roleplay-sessions | Проверенный сценарий, настроение и рубрика |
| POST /roleplay-sessions/{id}/messages | Следующий ход, без произвольного автоматического балла |
| PUT /terms/{id}/mastery | Повторение словаря отдельно от экзамена |
| POST /review/conflicts/{id}/resolution | Решение тренера с обоснованием, датой и аудиторским следом |

Эти адреса сейчас возвращают 404. Не создавать кнопки к ним до завершения соответствующих этапов. Оценка открытого ответа — по явным критериям с доказательствами из ответа, ручной проверкой спорных случаев; одна лишь похожесть текста не является оценкой.

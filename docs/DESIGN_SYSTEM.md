Учебная платформа с собственным интерфейсом. В таблице отмечены рабочие экраны и экраны следующих этапов.

Системный Segoe UI/Arial, без сетевых шрифтов. H1 26–36 px, H2 19 px, текст лекции 17 px, основной 16 px, библиография 12 px. Шаг отступов 4 px; основные 12/18/24/40. Панель radius 12 px, элементы управления 8 px. Sidebar 248 px, область контента max 1300 px, чтение max 880 px. Tailwind подключён через официальный Vite plugin, общие токены — CSS variables. Избегать расхождения утилит и значений CSS.

## Переиспользуемые компоненты

Реализованы `Panel`, `QueryState`, `SourceCitation`, `LessonCard`. Shell содержит Sidebar, Header, main и skip-link. SourceCitation показывает статус словами, файл, страницу/слайд/ячейку и дату; цвет не является единственным носителем смысла. QueryState различает ожидание/ошибку и даёт реальную кнопку повторного запроса.

Далее выделить `Button`, `FormField`, `PageTitle`, `EmptyState`, `DataTable`, `StatusLabel`, `Dialog`, `QuestionCard`, `AnswerEditor`, `RubricReview`, `CustomerSummary`, `Transcript`, `TermCard`. Компоненты отображения не обращаются к БД, запросы размещать в feature hooks.

## Доступность и адаптивность

Клавиатурные focus-visible, семантические nav/main/header, aria-pressed у отметки, aria-live через role=status для успешной записи, role=alert для ошибки. На 700 px Sidebar превращается в верхнюю навигацию, карточки становятся одной колонкой. Широкие таблицы CRM прокручиваются внутри контейнера. Тёмная тема сохраняется после reload. При недоступном localStorage тема всё равно переключается в памяти.

Проверены Chromium 1440×1000 и 390×844. Полная проверка экранным диктором и всех будущих компонентов остаётся задачей следующих этапов.

## Пакет задания для GPT-6.1 Sol High

Передавать один этап таблицы за раз, вместе с AGENTS.md, этой документацией, схемой и локальным reviewed_content.json. Не передавать полные приватные документы в публичные тикеты. Указать конкретный контракт API, ожидаемый сценарий и команды проверок. Сохранять архитектуру монолита, использовать текущий lockfile. Не менять спорную банковскую формулировку ради прохождения теста. Не выдавать вопросы за официальный экзамен тренера.

Критерии приёмки каждой задачи: работающий код, подходящий тест поведения, обновлённые API/README при изменении контракта, `alembic check`, `pytest`, `npm run build`, `npm test`, затронутый E2E, `scripts/check_privacy.py`. Не запускать весь следующий этап автоматически.

## Известные границы

Сегодня нет пользовательской аутентификации, сервера в LAN, UI редактирования контента, оценки Roleplay и механизма продолжения теста из старого чата. Последнее невозможно без отсутствующих вопросов/ответов. Данные экзамена 13 ноября 2026 из исходного JSON — учебный контекст, не официальный сертификат. Полный аудит актуальности правил банка вне переданных лекций не выполнялся.

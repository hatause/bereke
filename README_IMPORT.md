# Как передать этот чат и материалы в Codex

В Codex нет автоматического переноса всей истории обычного ChatGPT-чата. Этот архив — подготовленный контекст для разработки на основании нашего разговора и твоих вложений.

## Локальный способ (рекомендуется)
1. Распакуй этот ZIP в папку `bereke-operator-academy` на компьютере.
2. Открой эту папку в Codex для компьютера или в VS Code с Codex.
3. В новом чате Codex отправь текст из `PROMPT_TO_CODEX.txt`.
4. Codex увидит `AGENTS.md`, а по заданию прочитает `CODEX_TASK.md`, `data/` и оригиналы в `sources/private/`.
5. Попроси сначала создать рабочий MVP, затем улучшить дизайн и увеличить банк вопросов.

## Если Codex работает в облаке на GitHub
- Codex получает файлы из выбранного репозитория, а не автоматически из этого ChatGPT-чата.
- В архиве есть `sources/private/` с исходными рабочими материалами. НЕ загружай их в публичный репозиторий: `.gitignore` специально исключает эту папку.
- Для облачной задачи нужны отдельно согласованные к загрузке материалы или обезличенные `data/` файлы. Если источники недоступны Codex, он должен явно сообщить, какие вопросы не удалось подтвердить.

## Что передаётся
- `AGENTS.md`: правила Codex.
- `CODEX_TASK.md`: подробное ТЗ.
- `data/lessons_seed.json`: структура кратких лекций по 4 дням.
- `data/terms_from_excel.json`: банковский словарь со вкладками и определениями из Excel.
- `data/exam_state_from_chat.json`: текущие результаты подготовки.
- `sources/private/*`: твои исходные файлы.

Отсутствуют: закрытый Notion, скрытые комментарии, отдельный сервисный гайд, реальные данные клиентов, доступ к реальным CRM.
